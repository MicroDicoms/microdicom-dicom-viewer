MicroDicom DICOM Viewer 2026.5

MicroDicom DICOM Viewer opens and reviews DICOM images and studies on Windows. Version 2026.5 supports 32-bit and 64-bit Windows 7, Windows 8, Windows 8.1, Windows 10, and Windows 11.

This release archive contains the unchanged Windows setup program and installation information.

  • Installer: Windows setup EXE for x86 and x64 systems
  • Silent installation: use the uppercase /S option; architecture options are listed in the included INSTALLATION.txt
  • Free for non-commercial use; commercial use requires a license

Review the official download page and official licensing information for current terms. MicroDicom product website.
